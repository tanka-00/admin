Accessibility notes

  • Use text + icons + color for status; never color alone.
  • Keep body text on light surfaces in #172A3A or darker.
  • Use bright turquoise for emphasis, not large text blocks.
  • Keep #FFB703 as a supporting highlight, not a primary brand surface.
